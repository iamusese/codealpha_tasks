# Zomato UX Case Study

## Overview

This project analyzes the user experience of the Zomato mobile application.

The study covers:

- User Journey Analysis
- UX Strengths
- UX Weaknesses
- Suggested Improvements
- Low-Fidelity Mockups

## Objective

To evaluate the current user experience and propose solutions that improve usability, efficiency, and customer satisfaction.

## Deliverables

- UX Case Study Report
- User Journey Mapping
- Improvement Recommendations
- Wireframe Concepts

- Figma
- Google Docs
